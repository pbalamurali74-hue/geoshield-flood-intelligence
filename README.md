# 🛰️ GeoShield — Flood Intelligence & Emergency Decision Support

**GEOIMPathon 1.0 • Problem Statement 4.4 — Disaster Exposure Mapping**

GeoShield converts **Sentinel-1 SAR flood detection** into explainable exposure analysis and emergency-priority intelligence.

## Core capabilities
- Sentinel-1 SAR flood detection.
- Building, road, cropland and population-proxy exposure analysis.
- 1 km² decision sectors.
- Explainable multi-factor priority scoring.
- Ranked emergency-response zones.
- Interactive MapLibre command center.
- Reproducible Python geospatial pipeline.

## Data
Sentinel-1 SAR • Copernicus DEM • JRC Global Surface Water • ESA WorldCover • OpenStreetMap

## Architecture
```
Satellite / GIS Data
       ↓
Geospatial Processing
       ↓
SAR Flood Detection
       ↓
Exposure Analysis
       ↓
Priority Scoring
       ↓
Interactive Dashboard
```
